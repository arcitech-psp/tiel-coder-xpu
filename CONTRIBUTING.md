# Contributing

Thanks for taking a look. Small, reproducible improvements are welcome.

- Please keep benchmark changes accompanied by exact hardware, software,
  settings, and a result JSON without private prompts.
- Do not submit calibration conversations, credentials, model weights, local
  paths, hostnames, or deployment logs.
- Keep claims tied to measurements. If a test was not run, say so.
- For questions or feedback, email parthpatel266@gmail.com or use
  `FEEDBACK_FORM_URL` when the form is live.
